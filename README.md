# CLAPAnalysis_sge pipeline

Fastq files were processed using the [CLAPAnalysis_sge pipeline](https://github.com/lconde-ucl/CLAPAnalysis_sge), as described there. The pipeline uses Bowtie2 and STAR indexes for human (hg38), mouse (mm10), or mixed human–mouse genome, which were generated as follows: 

### Bowtie2 repeat indexes

The repeat indexes were generated using the human and mouse small RNA FASTA files provided by the [nf-core clipseq](https://nf-co.re/clipseq/1.0.0/) pipeline. The files were downloaded and combined to generate a mixed human–mouse FASTA file. Bowtie2 indexes were then generated separately for the human, mouse and mixed references:

```
#- download RNAs from nf-core/clipseq repository
wget https://github.com/nf-core/clipseq/raw/refs/heads/master/assets/small_rna/Mus_musculus/Mus_musculus.smallRNA.fa.gz
wget https://github.com/nf-core/clipseq/raw/refs/heads/master/assets/small_rna/Homo_sapiens/Homo_sapiens.smallRNA.fa.gz

gunzip Mus_musculus.smallRNA.fa.gz
gunzip Homo_sapiens.smallRNA.fa.gz

cat Homo_sapiens.smallRNA.fa Mus_musculus.smallRNA.fa > nfcorerepeats.hg38.mm10.fasta

#- create bowtie indexes
mkdir bowtie2_index_nfcore

bowtie2-build Homo_sapiens.smallRNA.fa bowtie2_index_nfcore/index_hg38_nfcorerepeats
bowtie2-build Mus_musculus.smallRNA.fa bowtie2_index_nfcore/index_mm10_nfcorerepeats
bowtie2-build nfcorerepeats.hg38.mm10.fasta bowtie2_index_nfcore/index_mixed_nfcorerepeats
```

### STAR indexes

The human and mouse reference genomes (UCSC hg38 and UCSC mm10, respectively), including their pre-built STAR indexes, FASTA files and GTF annotations, were downloaded from [AWS iGenomes](https://ewels.github.io/AWS-iGenomes/). The pre-built human and mouse STAR indexes were used directly. An additional STAR index for the mixed human–mouse genome was generated by combining the corresponding human and mouse FASTA and GTF files. The sequence names in the FASTA files and chromosome names in the GTF files were modified to distinguish the human and mouse sequences. The combined files were then used to generate the mixed STAR index:

```
#- download AWS iGenomes (UCSC/hg38 and UCSC/mm10).
bash aws-igenomes.sh -g Homo_sapiens -s UCSC -b hg38 
bash aws-igenomes.sh -g Mus_musculus -s UCSC -b mm10

# Combine human and mouse FASTA files
cp references/Homo_sapiens/UCSC/hg38/Sequence/WholeGenomeFasta/genome.fa genome.hg38.fa
perl -p -i -e 's/^(>.*)/${1}_human/g' genome.hg38.fa
cp references/Mus_musculus/UCSC/mm10/Sequence/WholeGenomeFasta/genome.fa genome.mm10.fa
perl -p -i -e 's/^(>.*)/${1}_mouse/g' genome.mm10.fa
cat genome.hg38.fa genome.mm10.fa > genome.hg38.mm10.fa

# Combine human and mouse GTF files
cp references/Homo_sapiens/UCSC/hg38/Annotation/Genes/genes.gtf genes_hg38.gtf
perl -p -i -e 's/^(chr[^\t]*)\t/${1}_human\t/' genes_hg38.gtf
cp references/Mus_musculus/UCSC/mm10/Annotation/Genes/genes.gtf genes_mm10.gtf
perl -p -i -e 's/^(chr[^\t]*)\t/${1}_mouse\t/' genes_mm10.gtf
cat genes_hg38.gtf genes_mm10.gtf > genes_hg38_mm10.gtf

#- Create mixed STAR index
mkdir index_mixed
~/.conda/envs/sprite/bin/STAR --runThreadN 2 \
    --runMode genomeGenerate \
    --genomeDir index_mixed \
    --genomeFastaFiles genome.hg38.mm10.fa \
    --sjdbGTFfile genes_hg38_mm10.gtf \
    --sjdbOverhang 100

```
